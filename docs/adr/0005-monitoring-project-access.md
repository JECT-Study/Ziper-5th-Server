# 0005 공유 Education 조직의 프로젝트별 모니터링 접근

- 상태: 채택; 프로젝트 이전·팀 배정·수집 확인, 실제 초대 구성원 접근 검증 대기
- 날짜: 2026-11-02

## 배경

Sentry Education 구독은 기존 tocktock의 `client`와 `server`가 있는 `joonamin-project` 조직에 적용되어 있습니다. 집어를 위해 만든 `ject-5th-team6` 조직은 Developer 구독이어서 팀 초대와 Discord 연동에 제한이 있습니다. 사용자는 기존 Education 조직에 집어를 추가하고 담당자가 배정된 프로젝트의 데이터만 보도록 요청했습니다. 이슈 조작까지 금지하는 읽기 전용 역할은 요구하지 않습니다.

## 결정

Education 조직에 집어 프로젝트를 이전하고 `ziper-server`로 식별합니다. 기존 tocktock 프로젝트와 `fakedev` 팀은 유지합니다. 집어 프로젝트는 새 `ziper` 팀에만 연결합니다. 조직의 Open Membership은 끄고 기본 조직 역할은 Member로 유지합니다. 향후 초대 시 담당 팀만 지정하며 프로젝트 담당자에게 조직 전체 권한인 Owner나 Manager를 부여하지 않습니다. 현재 초대 명단은 전달되지 않아 추가 인원을 초대하지 않습니다.

프로젝트 이전이 가능하면 이벤트와 설정을 보존합니다. 삭제 후 재생성은 이전이 불가능할 때의 대안입니다. 이전 후 프로젝트 ID, 키, 수집, 소스 문맥 업로드와 대시보드를 확인하고 저장소 설정을 같은 변경에서 맞춥니다. 조직 이전을 위해 구독을 변경하거나 새 유료 플랜을 시작하지 않습니다.

## 대안

- 별도 유료 조직: 프로젝트와 관리자를 조직 단위로 분리할 수 있지만 추가 비용 때문에 선택하지 않았습니다.
- Open Membership 유지: 구성원 스스로 다른 프로젝트의 팀에 가입할 수 있어 접근 분리 요구에 맞지 않습니다.
- 프로젝트 삭제 후 재생성: 기존 이벤트와 설정을 잃으므로 이전이 가능한 경우 사용하지 않습니다.

## 영향과 한계

조직 구독과 사용량 한도는 프로젝트들이 공유합니다. 조직 Owner와 Manager는 전체 프로젝트를 관리할 수 있으므로 이 역할은 프로젝트별 접근 분리의 대상이 아닙니다. Member에게도 배정된 프로젝트에서 이슈 처리 등의 권한이 있으며 읽기 전용을 보장하지 않습니다.

Sentry의 프로젝트 이전은 같은 저장 리전 사이에서 지원됩니다. 공식 안내상 이벤트와 프로젝트 설정은 이전되지만 릴리스와 세션 이력은 이전되지 않습니다. 소스 문맥 업로드 인증은 대상 조직에 맞춰 다시 확인해야 합니다. 팀 배정과 Open Membership 설정 검증은 초대받은 실제 구성원의 접근 검증을 대신하지 않습니다.

2026-11-03 확인 결과 프로젝트 ID를 유지한 이전이 완료됐습니다. `client`·`server`의 팀은 `fakedev`, `ziper-server`의 유일한 팀은 `ziper`이며 Open Membership은 꺼져 있습니다. 새 조직에서 오류·트레이스·지표 수신과 소스 번들 업로드를 확인했습니다. 초대 명단과 대상 Discord 서버의 봇 설치는 대기 중입니다. [검증 기록](../verification.md#2026-11-03-education-조직-이전과-실제-수신-검증)
